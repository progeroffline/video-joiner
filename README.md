# video-joiner

CLI-утилита для пакетного объединения MP4-файлов без перекодирования видео. Она
рекурсивно обходит переданное дерево каталогов, отдельно обрабатывает каждый
каталог с частями и сохраняет результат рядом с ними под именем `video.mp4`.

```text
downloads/
├── stream-1/
│   ├── part-1.mp4 ─┐
│   └── part-2.mp4 ─┴─→ stream-1/video.mp4
└── archive/
    └── stream-2/
        ├── chunk-1.mp4 ┐
        └── chunk-2.mp4 ┴─→ archive/stream-2/video.mp4
```

## Основные возможности

- рекурсивный обход корневой директории;
- независимое объединение MP4-файлов в каждом найденном каталоге;
- сортировка частей по времени создания — от старых к новым;
- объединение через FFmpeg с `-c copy`, без перекодирования видео;
- предварительная проверка совместимости частей через `ffprobe`;
- отображение параметров файлов и прогресса объединения;
- пропуск каталогов, в которых уже существует `video.mp4`;
- автоматическое удаление исходных MP4 после проверки результата;
- режим проверки без изменения файлов (`--dry-run`).

> **Важно:** по умолчанию после успешного создания и проверки `video.mp4`
> исходные MP4 удаляются с диска, а не перемещаются в корзину. Для сохранения
> исходников используйте `--keep-sources`.

## Порядок обработки

Для каждого каталога утилита:

1. Находит MP4-файлы, лежащие непосредственно в нём. Вложенные каталоги
   обрабатываются как отдельные группы.
2. Исключает зарезервированный итоговый файл `video.mp4` из списка частей.
3. Сортирует части по времени создания. При одинаковом времени используется
   имя файла.
4. Проверяет кодеки, разрешение и параметры аудио.
5. Объединяет части в `video.mp4` без перекодирования видео.
6. Проверяет созданный результат через `ffprobe`.
7. Если результат читается корректно, удаляет исходные MP4.

Если `video.mp4` уже существует, повторное объединение без `--force` не
выполняется. Готовый файл проверяется через `ffprobe`, после чего оставшиеся
рядом исходные MP4 удаляются. Остальные каталоги продолжают обрабатываться.

Если существующий `video.mp4` повреждён или не был дописан (например, FFmpeg
сообщает `moov atom not found`), каталог автоматически возвращается в очередь:
результат пересоздаётся из сохранившихся частей. Повреждённый файл не считается
успешным результатом и не приводит к удалению исходников.

Расширение `.mp4` распознаётся без учёта регистра. Файлы других типов не
объединяются и не удаляются.

## Сортировка по дате создания

На macOS используется filesystem birth time — время создания файла. Если
операционная или файловая система не предоставляет birth time, используется
`ctime`, то есть время последнего изменения метаданных файла.

## Совместимость частей

Объединение выполняется через concat demuxer FFmpeg:

```bash
ffmpeg -f concat -safe 0 -i files.txt -map 0:v -map 0:a? -c copy video.mp4
```

Такой способ работает быстро и не нагружает CPU кодированием, но части должны
иметь совместимые параметры. Утилита блокирует объединение при различиях в:

- видеокодеке;
- разрешении;
- аудиокодеке;
- частоте дискретизации аудио;
- количестве аудиоканалов.

В итоговый MP4 копируются видео и все доступные аудиопотоки. Служебные
data-потоки (например, `timed_id3`), которые MP4 не поддерживает, намеренно
игнорируются. Они не содержат само видео или звук.

Сначала программа пытается скопировать аудио без перекодирования. Если FFmpeg
обнаруживает повреждённый AAC/ADTS-пакет, выполняется автоматическая повторная
попытка: повреждённые пакеты пропускаются, видео продолжает копироваться без
перекодирования, а аудио перекодируется в AAC. Исходники удаляются только если
эта попытка завершилась успешно и созданный `video.mp4` прошёл проверку.

Средний FPS показывается в таблице, но различия FPS не блокируют попытку
объединения. Среднее значение может отличаться из-за таймстампов, пропущенных
кадров или переменной частоты кадров.

Если хотя бы одна новая группа несовместима, запись и удаление файлов в этом
запуске отменяются. Видео автоматически не перекодируется; аудио
перекодируется только в описанном выше аварийном режиме восстановления AAC.

После склейки программа также сообщает о предупреждениях FFmpeg, связанных с
некорректными DTS. В этом случае рядом создаётся служебная метка
`.video-joiner-needs-review`, а исходники сохраняются для ручной проверки.
Следующие запуски также не удаляют их автоматически. Успешная принудительная
пересборка без DTS-предупреждений снимает метку.

## Требования

- Python 3.11+
- FFmpeg и ffprobe в `PATH`
- [uv](https://docs.astral.sh/uv/)

Установка FFmpeg на macOS:

```bash
brew install ffmpeg
```

На Debian/Ubuntu:

```bash
sudo apt install ffmpeg
```

## Установка

```bash
uv sync
```

## Использование

Сначала рекомендуется проверить, какие каталоги и файлы будут обработаны:

```bash
uv run video-joiner ./downloads --dry-run
```

Объединить файлы и удалить успешно обработанные исходники:

```bash
uv run video-joiner ./downloads
```

Объединить файлы, сохранив исходники:

```bash
uv run video-joiner ./downloads --keep-sources
```

Пересобрать существующие `video.mp4`, если рядом ещё остались исходники:

```bash
uv run video-joiner ./downloads --force
```

Подробный вывод команд FFmpeg и метаданных:

```bash
uv run video-joiner ./downloads --verbose
```

Утилиту также можно запускать напрямую:

```bash
uv run python main.py ./downloads --dry-run
```

### Аргументы и флаги

- `directory` — обязательная корневая директория для рекурсивного обхода;
- `--dry-run` — проверить новые части и показать план без создания и удаления
  файлов;
- `--keep-sources` — не удалять исходные MP4;
- `--force` — пересобрать и перезаписать существующие `video.mp4`;
- `--verbose` — включить подробные логи.

Флаги можно комбинировать, например:

```bash
uv run video-joiner ./downloads --force --keep-sources --verbose
```

## Повторный запуск

Обычный повторный запуск безопасно продолжает незавершённую обработку:

- каталоги только с `video.mp4` не требуют действий;
- каталоги с `video.mp4` и оставшимися частями очищаются после проверки
  результата;
- повреждённые или недописанные `video.mp4` автоматически пересобираются из
  оставшихся частей;
- каталоги без `video.mp4` объединяются как обычно;
- для принудительной пересборки используется `--force`.
