# video-joiner

Простая CLI-утилита для объединения нескольких последовательных частей видео
в один файл без перекодирования, с использованием FFmpeg.

```text
part1.mp4 + part2.mp4 + part3.mp4  →  full.mp4
```

## Как это работает

Объединение выполняется через concat demuxer FFmpeg с флагом `-c copy`:

```bash
ffmpeg -f concat -safe 0 -i files.txt -map 0 -c copy full.mp4
```

Видео и аудио потоки копируются как есть, без повторного кодирования.
Это быстро, не нагружает CPU и не теряет качество — но требует, чтобы
все части были в одинаковом формате (кодек, разрешение, FPS, аудио).

Перед объединением утилита проверяет части через `ffprobe` и сравнивает
их параметры. Если части несовместимы, программа не будет перекодировать
их автоматически — она покажет, чем именно они отличаются, и остановится.

## Требования

- Python 3.11+
- FFmpeg и ffprobe в `PATH`
- [uv](https://docs.astral.sh/uv/) для управления зависимостями

### Установка FFmpeg

macOS:

```bash
brew install ffmpeg
```

Debian/Ubuntu:

```bash
sudo apt install ffmpeg
```

## Установка

```bash
uv sync
```

## Использование

```bash
uv run python main.py part1.mp4 part2.mp4 part3.mp4 -o full.mp4
```

После `uv sync` также доступна команда:

```bash
uv run video-joiner part1.mp4 part2.mp4 part3.mp4 -o full.mp4
```

### Полезные флаги

- `-o, --output PATH` — путь к итоговому файлу (обязательный)
- `--force` — перезаписать `output`, если он уже существует
- `--verbose` — подробные логи (команды FFmpeg, метаданные ffprobe, предупреждения)
- `--dry-run` — только проверить файлы и совместимость, ничего не создавая

## Если файлы несовместимы

Если у частей разный видеокодек, разрешение, FPS, аудиокодек, частота
дискретизации или число каналов — утилита остановится и покажет список
конкретных отличий. Перекодировать такие файлы автоматически она не будет:
приведите части к одному формату вручную (например, через отдельный
`ffmpeg -c:v ... -c:a ...`) и запустите склейку заново.

## Предупреждения о таймстампах

FFmpeg иногда сообщает о проблемах с таймстампами при склейке (`Non-monotonous
DTS` и подобные). Такие сообщения не приводят к остановке склейки, но
утилита явно выведет предупреждение после завершения — в этом случае
стоит проверить итоговый файл вручную.
