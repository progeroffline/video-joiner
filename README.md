# video-joiner

CLI-утилита рекурсивно обходит дерево директорий и объединяет MP4-файлы
в каждой директории в локальный `video.mp4` без перекодирования.

```text
records/
├── stream-1/
│   ├── part-a.mp4 ─┐
│   ├── part-b.mp4 ─┴─→ stream-1/video.mp4
└── stream-2/
    ├── chunk-1.mp4 ┐
    └── chunk-2.mp4 ┴─→ stream-2/video.mp4
```

Части сортируются по времени создания файла — от самого старого к самому
новому. При одинаковом времени используется имя файла. Уже созданный
`video.mp4` не считается исходной частью.

На macOS используется filesystem birth time. На платформах, где файловая
система или Python не предоставляют время создания, используется `ctime`
(время последнего изменения метаданных файла).

## Как это работает

Объединение выполняется через concat demuxer FFmpeg с `-c copy`. Видео и
аудио копируются как есть, поэтому операция выполняется быстро и без потери
качества. Исходные части должны иметь совместимые кодеки, разрешение, FPS и
параметры аудио.

Перед началом записи утилита проверяет все найденные группы через `ffprobe`.
Если хотя бы одна группа несовместима, обработка целиком отменяется.

## Требования

- Python 3.11+
- FFmpeg и ffprobe в `PATH`
- [uv](https://docs.astral.sh/uv/)

macOS:

```bash
brew install ffmpeg
```

Debian/Ubuntu:

```bash
sudo apt install ffmpeg
```

## Установка и запуск

```bash
uv sync
uv run video-joiner ./records
```

Можно также запустить модуль напрямую:

```bash
uv run python main.py ./records
```

### Флаги

- `--force` — перезаписать уже существующие `video.mp4`;
- `--verbose` — показать команды FFmpeg, метаданные и подробные ошибки;
- `--dry-run` — найти и проверить все части, но ничего не создавать.

Без `--force` наличие `video.mp4` в любой директории, где найдены исходные
части, останавливает запись файлов. В режиме `--dry-run` существующие результаты
не мешают проверке.

## Порядок обработки

Утилита обходит корневую директорию и все вложенные директории. Для каждого
каталога учитываются только `.mp4`, лежащие непосредственно в нём. Расширение
сопоставляется без учёта регистра. Поддиректории обрабатываются как отдельные
группы.

## Разработка

```bash
uv sync
uv run python -m unittest discover -s tests
uv run video-joiner --help
```
